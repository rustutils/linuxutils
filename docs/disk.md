# Disk

Tools for working with block devices, partition tables, and filesystem
images.

## Implemented

- [`blockdev`](disk/blockdev.md) — call block device ioctls from the command line
- [`isosize`]() — output the length of an iso9660 filesystem

## Planned

`addpart`, `cfdisk`, `delpart`, `fdformat`, `fdisk`, `fsck`, `fsck.cramfs`,
`fsck.minix`, `mkfs`, `mkfs.bfs`, `mkfs.cramfs`, `mkfs.minix`, `mkswap`,
`partx`, `raw`, `resizepart`, `sfdisk`, `swaplabel`.
