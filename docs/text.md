# Text

Text-processing tools.

## Implemented

- [`colrm`](text/colrm.md) — remove columns from a file
- [`column`]() — columnate lists
- [`hexdump`](text/hexdump.md) — display file contents in hexadecimal, decimal, octal, or ascii
- [`line`](text/line.md) — read one line
- [`rev`](text/rev.md) — reverse lines characterwise
