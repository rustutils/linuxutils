# Terminal

Terminal-facing tools for sending messages to other users and controlling
terminal access.

## Implemented

- [`mesg`](term/mesg.md) — display (or do not display) messages from other users
- [`wall`]() — write a message to all users
- [`write`]() — send a message to another user

## Planned

`agetty`, `script`, `scriptlive`, `scriptreplay`, `setterm`.
